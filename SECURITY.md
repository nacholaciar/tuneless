# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Do not disclose potential vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, macOS version, impact, reproduction steps, and any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow a reasonable remediation window before public disclosure.

Tuneless runs as your user, makes no network requests, and only quits processes whose bundle identifier is `com.apple.Music` or `com.apple.iTunes`.
